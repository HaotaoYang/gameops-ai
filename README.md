# GameOps AI Agent

一个用于学习 AI 应用开发的游戏运营智能分析项目。

## 技术背景

- 原有技术：Erlang / OTP
- 新学习语言：Python 3.12
- 学习目标：AI Application Backend / AI Agent

## 最终功能

1. 查询游戏玩家数据
2. 查询服务器统计数据
3. 查询游戏活动配置
4. 使用 RAG 检索游戏规则
5. 使用 AI Agent 分析运营数据
6. 生成有数据依据的分析报告

## 开发环境

- macOS
- Python 3.12
- Git
- VS Code

## 运行方式

创建并激活虚拟环境：

    python3.12 -m venv .venv
    source .venv/bin/activate

运行程序：

    python hello.py
